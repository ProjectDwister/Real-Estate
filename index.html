Methodology & data quality

Primary source

Maharashtra IGR registration search metadata and selected Index II extracts collected from the public portal.

Public-data policy

Seller and purchaser names are stripped before publishing. Raw downloads remain local and are git-ignored.

Price metrics

Sale ₹/sq ft is shown only when transaction consideration and a usable area are available. Missing values are not imputed.

Updates

GitHub Pages redeploys automatically whenever the sanitized dataset is pushed. IGR captcha remains a human step where required.
